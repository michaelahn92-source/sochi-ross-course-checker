# SOCHI Course Review

## Platform
web

## Stack
Delegated by the user: Python WSGI with a plain HTML/CSS/JavaScript interface; Render free web service. Existing openpyxl for workbooks; NumPy for offline training only.

## Users
Glenn's Business+Impact team and student temp, reviewing four course lists before each semester.

## Product Purpose
Compare the four course workbooks with official term offerings. Suggest term updates, reactivation, renumbering candidates, stale course review, and new course discovery. Export review decisions without changing source spreadsheets.

## Capabilities and Constraints
Offline ridge regression for match ranking. Deterministic exact schedule evidence. No required API or LLM. Optional Glen-provided U-M GPT Toolkit only. No automatic production writes. Catalog coverage and usage guide included. Incomplete history must never imply a course has been discontinued.

## Brand Commitments
